# 主流记忆产品与间隔重复机制调研

> 调研日期：2026-08-17  
> 研究目的：为“英语口语练习助手”的句子复习与个人词典设计可解释、可实现的学习机制。  
> 来源边界：仅采用产品官网、官方应用商店说明、官方手册、算法作者/维护者发布的资料。产品没有公开的细节不做猜测。

> 产品决策更新：本项目最终不采用本文建议的 FSRS 复习交互，也不做独立单词卡、隐藏答案或连续多次掌握判定。本文仅作为“内容可按日期再次出现”这一学习思路的背景调研；正式产品规则以 `docs/product/mvp-prd.md` 和 `docs/product/ui-flow.md` 为准。

## 结论摘要

1. 百词斩和不背单词都公开强调“重复复习 + 多种训练形式 + 记忆辅助”，但没有公开可复刻的完整排程公式、参数或逐次间隔。因此，我们可以借鉴它们的产品思路，不能声称采用了与其相同的算法。
2. 对本项目最合适的首版方案是：用“先回忆、后揭晓、再自评”的复习交互，底层采用 FSRS 一类基于历史表现动态排程的算法。
3. 用户界面可以继续只保留“✓ 掌握 / ✕ 未掌握”两个按钮。Anki 官方手册明确允许只使用 `Again` 与 `Good` 两档；这两档可直接映射为本项目的叉号与对号。
4. “连续几次掌握”不应理解为同一天连续点击几次，而应是跨多个排程日期连续回忆成功。项目可把“连续 3 次跨日成功且达到稳定度阈值”作为已掌握的产品标记；底层仍保留复习记录，之后可以继续按算法复现。
5. 不建议硬编码统一的 `1、3、7、14、30 天`。固定间隔可作为无历史数据时的降级方案，但正常情况应根据每个用户、每个句子或单词的实际表现计算下次复习时间。

## 1. 百词斩：公开可确认的机制

### 公开事实

- 百词斩官方 App Store 页面列出多种学习模式，包括深度、图片、押韵和儿童背词模式；词条内容包含读音、单词变形和多类辅助素材。[百词斩 App Store 官方产品说明](https://apps.apple.com/cn/app/%E7%99%BE%E8%AF%8D%E6%96%A9-%E5%AD%A6%E5%A4%96%E8%AF%AD-%E8%83%8C%E5%8D%95%E8%AF%8D%E5%BF%85%E5%A4%87/id557545298)
- 其公开的复习题型包括英文选义、中文选词、拼写、读词填空和单词速听，即通过不同方向的识别、回忆、拼写与听力任务反复接触同一词项。[百词斩 App Store 官方产品说明](https://apps.apple.com/cn/app/%E7%99%BE%E8%AF%8D%E6%96%A9-%E5%AD%A6%E5%A4%96%E8%AF%AD-%E8%83%8C%E5%8D%95%E8%AF%8D%E5%BF%85%E5%A4%87/id557545298)
- 百词斩官网公开展示“图背单词”和“6 种复习模式”。[百词斩官方下载页](https://www.baicizhan.com/download)
- 百词斩官方单词机页面宣称其产品使用经过用户学习数据验证的“独家记忆曲线”，并把情景图片作为建立单词与真实环境联系的手段。[百词斩单词机官网](https://danciji.baicizhan.com/)
- 百词斩官方小讲堂反对机械照搬固定的“艾宾浩斯时刻表”：其建议把复习分散在几天内，但具体间隔按实际学习情况决定；文中还说明百词斩采用控制每日新学量与复习量的产品设计。[百词斩官方小讲堂：如何正确使用艾宾浩斯遗忘曲线背单词？](https://www.baicizhan.com/little_class/article/824/share_view)

### 公开信息的边界

百词斩没有在上述官方页面公开其“记忆曲线”的数学模型、输入信号、评分映射、具体参数或每次复习间隔。因此：

- 可以确认它会安排复习并提供多种复习形式；
- 不能确认它是否使用 SM-2、FSRS 或某个固定的“艾宾浩斯时间表”；
- 不能从公开材料推出“答对几次算掌握”或精确的复习日期。

- 不背单词官网将其能力概括为“科学记忆算法”。[不背单词官网](https://bbdc.cn/)

### 公开信息的边界

不背单词公开了所依据的记忆曲线概念、语境材料和训练形式，但没有在上述页面公开完整算法、个性化参数、复习间隔计算公式或“掌握”判定规则。因此，同样不能精确复制其排程。

## 3. Anki 与 FSRS：公开、可实现的参考机制

### 主动回忆与评分

- Anki 的标准学习流程是先只显示问题，让用户尝试回忆，再显示答案并自评。这比在答案始终可见时直接点击掌握更接近一次有效的回忆测试。[Anki 官方手册：Questions](https://docs.ankiweb.net/studying.html#questions)
- Anki 的四档评分是 `Again / Hard / Good / Easy`；官方手册同时明确表示，如果四个按钮难以使用，可以只用 `Again` 和 `Good`，分别表示答错与答对。[Anki 官方手册：Answer Buttons](https://docs.ankiweb.net/studying.html#answer-buttons)
- `Again` 表示答案错误或无法回忆；`Good` 表示答案正确但需要一定回忆努力。每次评分会决定下一次出现时间。[Anki 官方手册：Answer Buttons](https://docs.ankiweb.net/studying.html#answer-buttons)

### FSRS 的记忆模型与个性化

- FSRS 用难度（Difficulty）、稳定度（Stability）和可提取率（Retrievability）表示记忆状态，并根据评分更新状态和下一间隔。[FSRS 官方算法说明](https://github.com/open-spaced-repetition/fsrs4anki/wiki/The-Algorithm)
- FSRS 的目标记忆率会影响复习负担：目标越高，间隔越短、每日复习越多。Anki 当前默认目标记忆率为 90%，官方将其描述为记忆效果与工作量之间的平衡点，并提示超过 97% 时负担可能过重。[Anki 官方手册：Desired Retention](https://docs.ankiweb.net/deck-options.html#desired-retention)
- FSRS 优化器可用用户的历史复习数据拟合更符合个人记忆模式的参数；在数据较少时需要先依赖默认参数，历史积累后再优化。[Anki 官方手册：FSRS Parameters](https://docs.ankiweb.net/deck-options.html#fsrs-parameters)
- 对 FSRS 而言，必须准确区分“忘记”和“虽然困难但仍想起”。如果忘记却记为通过，后续间隔会被错误拉长。[Anki 官方手册：FSRS](https://docs.ankiweb.net/deck-options.html#fsrs)

### 当日重复不等于长期掌握

- Anki 官方建议 FSRS 的学习/重学步骤保持在一天以内并尽量少；其手册指出，同一天多次重复对长期记忆的贡献有限。[Anki 官方手册：Learning and Relearning Steps](https://docs.ankiweb.net/deck-options.html#learning-and-relearning-steps)
- 新卡的学习步骤与遗忘后的重学步骤是独立概念；在传统步骤模式中，答错回到第一步，答对前进到下一步。[Anki 官方手册：Learning Steps](https://docs.ankiweb.net/deck-options.html#learning-steps)

## 4. SuperMemo：间隔重复的产品原则

- SuperMemo 官方把复习结果作为动态排程依据：容易且正确时拉长间隔，困难时提前复习，从而让每个学习项形成不同节奏。[SuperMemo 官方 FAQ：What is the SuperMemo method?](https://www.supermemo.com/en/faq/what-is-the-supermemo-method)
- SuperMemo 产品使用 `Know / Almost / Don't know` 三档自评，并由算法据此安排复习；记忆越好，后续间隔越长。[SuperMemo 官方方法说明](https://www.supermemo.com/en/supermemo-method)
- SuperMemo 官方称其默认在预计回忆概率降至 90% 左右时安排复习，并根据每次学习数据更新个人的遗忘曲线。[SuperMemo 官方 FAQ：How often should the material be repeated?](https://www.supermemo.com/en/faq/how-often-should-the-material-be-repeated)
- SuperMemo 的早期 SM-2 使用每个学习项的难度因子调整间隔；现代 SuperMemo 已迭代到后续私有算法。因此，“采用 SM-2”不能等同于“采用当前 SuperMemo 算法”。[SuperMemo 官方算法许可说明](https://www.supermemo.com/en/blog/licensing-and-copyrighting-of-supermemo-algorithms)

## 5. 对本项目的设计建议

以下内容是基于上述公开事实做出的产品与技术建议，不是对百词斩或不背单词内部实现的描述。

### 5.1 两种复习对象，统一调度

将复习项定义为两类：

1. **句子项**：来自某个学习单元中被用户打叉的句子，保留中文原句、英文句子、句子音频和原段落上下文。
2. **单词项**：用户在单词详情页主动点击“收藏/加入个人词典”的单词，保留它在原句中的语境义，同时关联词典释义、音标、发音、词形、搭配和例句。

两类项目使用同一个复习队列和排程接口，但分别维护自己的记忆状态与复习历史。用户掌握一个单词，不应自动代表其已能流利说出包含该词的整句；反之亦然。

### 5.2 复习交互采用“先回忆，后揭晓”

首次学习单元可以完整展示中英文，方便理解和跟读。进入第三页的复习模式后，建议：

- 句子：先显示中文和播放提示，让用户尝试说出英文；点击“显示答案”后再展示英文与播放标准音频；最后点击 ✓ 或 ✕。
- 单词：先显示英文单词或含空缺的原句，让用户回忆语境义或完成口头表达；揭晓后显示词义、发音和用法，再点击 ✓ 或 ✕。

如果答案一直可见，用户点击对号更多反映“看懂/熟悉”，不一定反映“能够独立说出”。

### 5.3 两按钮映射

| 产品按钮 | 调度评分 | 含义 | 调度结果 |
|---|---|---|---|
| ✕ 未掌握 | `Again` | 没说出、说错核心表达，或必须先看答案 | 计为一次遗忘，较早再次出现 |
| ✓ 掌握 | `Good` | 未看答案便基本正确说出或回忆出 | 增加稳定度，拉长下次间隔 |

首版不必暴露“困难”和“简单”两档，保持用户提出的极简交互。后台数据结构可预留 1–4 的通用评分字段，便于未来增加“勉强想起”等选项。

### 5.4 “连续掌握几次”的定义

建议把 UI 状态与底层排程分开：

- `LEARNING`：刚加入或最近答错；
- `REVIEWING`：已出现成功回忆，但尚未达到产品定义的稳定掌握；
- `MASTERED`：最近 **3 次到期复习均为 ✓**，三次不是同一天刷出，并且调度器估计的下一间隔已达到至少 14 天；
- `LAPSED`：曾掌握但后来点击 ✕，连续成功次数清零，重新进入待复习。

“已掌握”后，该项目从第三页默认的“待学习”列表移出，但不能删除历史，也不应永久停止排程。到期时仍可重新出现；用户可以在“已掌握”筛选中查看它。

`3 次 + 14 天` 是本项目的可调整产品阈值，不是百词斩、不背单词、Anki 或 FSRS 的公开标准。上线后应通过实际完成率、遗忘率和用户负担验证。

### 5.5 排程建议

首选方案：

- 使用成熟的开源 FSRS 实现；
- 初始目标记忆率设为 `0.90`；
- 新用户先使用算法默认参数，积累足够复习历史后再做个性化优化；
- 每个句子/单词独立保存 `due_at`、难度、稳定度、最近复习时间和状态；
- 所有评分都写入不可变的复习日志，账号登录后跨设备同步；
- 每日页面只取 `due_at <= 当前时间` 的待复习项，并为当日数量设置上限，避免积压造成挫败感。

降级方案：如果首版暂时不集成 FSRS，可短期采用如下可解释规则，但数据结构仍应兼容日后迁移：

- 首次 ✕：当天稍后短暂重学，次日进入复习；
- ✓：按 `1 → 3 → 7 → 14 → 30` 天逐级延长；
- ✕：成功级别清零，并在较短时间后重新出现；
- 连续三次跨日 ✓ 且进入 14 天级别后标记为 `MASTERED`。

这只是 MVP 降级排程，不应宣传为“艾宾浩斯算法”，也不应声称与百词斩或不背单词相同。

### 5.6 最小数据模型

每个复习项至少保存：

- `id`
- `user_id`
- `item_type`：`SENTENCE` / `WORD`
- `source_sentence_id`
- `source_learning_unit_id`
- `status`：`LEARNING` / `REVIEWING` / `MASTERED` / `LAPSED`
- `due_at`
- `consecutive_successes`
- `lapse_count`
- `scheduler_version`
- `scheduler_state`：调度器所需的难度、稳定度等状态
- `created_at` / `last_reviewed_at`

每次复习另外写入日志：

- `review_item_id`
- `rating`：首版为 `AGAIN` / `GOOD`
- `reviewed_at`
- `scheduled_days`
- `elapsed_days`
- `response_time_ms`（可选；首版不用于评分）

保留完整日志很重要，因为个性化 FSRS 参数和后续算法升级都依赖真实历史。

## 6. 不应对外宣称的内容

- 不要宣传“采用了和百词斩/不背单词完全一样的算法”，因为其完整算法未公开。
- 不要把固定的几个日期包装为“严格的艾宾浩斯遗忘曲线”；遗忘速度存在个体和材料差异。
- 不要把同一天连续三次点对号当作长期掌握。
- 不要因用户点一次对号就永久移除项目；“当前无需复习”和“永久掌握”是不同概念。

## 7. 推荐落地决策

本项目建议正式确定为：

> 学习单元负责理解、听读和跟读；复习页负责主动回忆。句子打叉或单词被收藏后成为独立复习项，采用二元自评（✓=`Good`、✕=`Again`）和 FSRS 动态排程。连续三次跨日成功且下次间隔达到 14 天时显示“已掌握”，之后仍保留历史并允许算法在未来再次安排复习。

这样既保留了用户想要的简单体验，也具备与主流间隔重复产品相同的核心学习思路：根据真实表现，把复习时间优先留给更容易遗忘的内容。
