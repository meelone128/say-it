# Say It：页面结构与交互流程

> 版本：0.8 草案  
> 更新日期：2026-08-17

## 1. 主导航结构

App 使用四个横向排列的主页面，不设置底部 Tab 栏。用户左右滑动切换页面，每个页面中的长内容上下滑动。

```text
[ 录音生成 ]  ⇄  [ 学习单元 ]  ⇄  [ 学习记录 ]  ⇄  [ 账号 / 设置 ]
     第 1 页             第 2 页                 第 3 页                 第 4 页
```

- App 启动后默认停留在第 1 页。
- 首次用户完成保存后，界面提示滑动到第 2 页开始学习。
- 主页面可以显示低干扰的分页位置提示，但不设置底部功能按钮。
- 进入学习单元详情或单词详情后使用层级导航，避免与主页面滑动手势冲突。

> 待交互原型确认：产品描述中的“往右滑到下一页”指的是手指向右滑，还是页面内容向右推进。原型阶段需要统一手势方向。

## 2. 第 1 页：录音生成

### 2.1 空闲状态

页面中心显示一个醒目的录音按钮，这是页面唯一的主要操作。

建议显示的辅助信息：

- 一句简短提示：“说一段中文，学会用自然英语表达。”
- 当前录音时长限制。
- 麦克风权限被拒绝时的说明。

### 2.2 录音状态

- 点击录音按钮后先启动底层采集，再显示短暂的“准备—现在可以说话”反馈；准备阶段的音频同样保留，防止句首丢失。
- 显示录音时长和录音中的视觉反馈。
- 支持暂停、继续、结束和试听。
- 单次录音最长 60 秒，到达上限后自动结束。

### 2.3 转换状态

录音结束后进入转换流程：

```text
上传录音
→ 识别中文
→ 生成自然美式口语
→ 拆分句子
→ 生成段落及逐句音频
→ 完成
```

- 转换期间显示当前进度。
- 用户离开当前页面后，任务仍可继续。
- 失败时显示重试入口，不能丢失已经完成的阶段。

### 2.4 转换结果与命名

转换完成后展示：

1. 中文识别段落。
2. 自然英语口语段落。
3. 重新生成入口。
4. 学习单元名称输入框。
5. 保存操作。

重新生成可以执行多次。当前结果在新结果成功前继续保留，避免生成失败导致内容丢失。

### 2.5 保存完成

- 学习单元写入学习列表。
- 新单元排在第 2 页顶部。
- 保存成功后自动切换到第 2 页。
- 第 2 页显示刚刚保存的学习单元名称、保存时间和内容摘要。

## 3. 第 2 页：学习单元

### 3.1 学习单元列表

学习单元以纵向滚动的方形卡片展示。每张卡片包含：

- 自定义名称。
- 保存时间。

每个学习单元就是一张已保存卡片。卡片保持简单，以名称为主、时间为辅，不在首版堆叠过多信息。

卡片采用左右交错排列：第一张靠左、第二张靠右、第三张再靠左，依次循环。卡片保持水平，不做随机旋转，避免影响阅读和点击。

```text
┌────────────┐
│ 第一次健身 │
│ 08-17 20:30│
└────────────┘

          ┌────────────┐
          │ 咖啡店点餐 │
          │ 08-16 18:20│
          └────────────┘

┌────────────┐
│ 工作会议   │
│ 08-15 09:10│
└────────────┘
```

- 卡片宽高接近 1:1，具体尺寸在视觉稿中根据屏幕宽度调整。
- 卡片之间保留足够纵向间距，整个页面上下滚动。
- 收藏单元可显示实心五角星并优先排列。

每个学习单元允许重命名和删除。删除前需要二次确认，并明确说明关联录音、音频和复习材料的处理方式。

点击一个学习单元进入详情。

### 3.2 学习单元详情：文章学习模式

页面顶部操作栏固定在同一行：

```text
[← 返回]                 [☆]  [ 检 ]
```

- 返回箭头位于左上角。
- 五角星是学习单元收藏按钮：空心表示未收藏，实心表示已收藏。
- “检”图标位于五角星右侧，点击进入检验模式。
- “检”图标使用圆形或近圆形底座，中间只显示一个“检”字，不显示完整的“检验模式”文字。
- 图标采用圆润、幼态的造型，尺寸和视觉重量与五角星接近。
- 首次使用时可以显示一次轻提示“进入检验模式”；同时为图标提供无障碍名称，避免用户只看到“检”字却不知道作用。
- 三个操作保持同一行，正文滚动时可以固定在顶部。

操作栏下方显示：

- 学习单元名称。
- 中文原段落。
- 完整英语段落。
- “全部播放”操作。

文章学习模式用于自由学习：

- 中文和英文以清晰的对照形式展示。
- 点击任意英文句子，播放该句音频。
- 点击任意英文单词，打开词典详情。
- 用户可以播放整段或逐句播放并自行跟读。

### 3.3 学习单元详情：检验模式

检验模式将文章拆成类似歌词的纵向句子列表，用户上下滑动浏览：

```text
▶  It was my first time at the gym today.

▶  I felt a little nervous at first.

▶  But I started to relax after a few minutes.
```

每句话支持：

- 点击播放该句。
- 播放后由用户自行跟读。
- 点击任意单词查看词典详情。
- 向左滑当前句子：判断为“已掌握”。
- 向右滑当前句子：判断为“未掌握”。
- 判断完成后当前句子从本次检验队列移出，并继续下一句。
- 已掌握句子进入第 3 页的“已掌握”卡片。
- 未掌握句子进入第 3 页的“未掌握”卡片，并在明天或以后再次出现。
- 滑动过程中同步显示绿色“已掌握”和红色“未掌握”提示，不能只依赖用户记忆方向。

首版不要求自动录制用户跟读，也不做发音评分。

## 4. 第 3 页：学习记录

页面只显示两张主要卡片，作为句子学习结果的入口。

```text
┌──────────────────┐
│   ✕ 未掌握        │
│  总数 / 今日数量   │
│  最近来源单元      │
└──────────────────┘

┌──────────────────┐
│   ✓ 已掌握        │
│  已掌握句子数量    │
│  查看学习成果      │
└──────────────────┘
```

### 4.1 未掌握卡片

- 展示检验模式中被判断为未掌握的句子。
- 用户收藏陌生单词时，将该单词所在的完整句子放入这里，并高亮收藏词、标明来源学习单元。
- 点击卡片进入未掌握句子列表。
- 点击句子播放标准音频，用户自行跟读。
- 到期内容排在前面，并显示“今天”“明天”“3 天后”或具体日期；未到期内容仍可随时查看。
- 向左滑表示已掌握，句子转入“已掌握”；向右滑表示仍未掌握并继续保留。
- 系统按日期安排未掌握句子在明天或以后重新进入检验。

### 4.2 已掌握卡片

- 展示检验模式中被判断为已掌握的句子。
- 点击卡片进入已掌握句子列表。
- 每条句子显示来源学习单元。
- 点击句子可以播放，点击单词仍可查看解释。
- 如果后来发现仍未掌握，可以向右滑重新放回“未掌握”。
- 已掌握记录不是删除原文；原句继续存在于所属学习单元中。

### 4.3 数据规则

- 每个句子必须保留所属学习单元关系。
- 同一句子只保留一条当前状态记录，不能同时出现在已掌握和未掌握中。
- 同一句中收藏多个单词时，只保存一条句子记录并高亮多个词。
- 进入已掌握或未掌握列表后，关闭四个主页面的横向切换手势；返回第三页后恢复。
- 账号用户的数据同步到云端。
- 游客数据暂存在本机，登录后可以合并到账号。

## 5. 词典详情

用户在任意英文句子中点击单词后，打开词典详情层。内容包括：

- 单词及原形。
- 美式音标和发音。
- 当前句子中的中文含义。
- 常用释义和词性。
- 常见词形变化。
- 必要的语法与搭配说明。
- 日常口语例句和中文解释。
- 原始上下文句子。
- “收藏该单词”操作；收藏后将当前完整句子加入未掌握列表，并高亮该词。

## 6. 第 4 页：账号与设置

- 游客状态展示注册和登录入口。
- 首版使用自定义用户名和密码。
- 建议注册时绑定并验证邮箱，用于找回密码。
- 登录后展示账号信息和云端同步状态。
- 提供退出登录、修改密码、管理本地数据和注销账号入口。
- 游客注册或登录时，可以把当前设备上的学习单元与复习进度合并到账号。

## 7. 状态与颜色规则

| 句子状态 | 视觉状态 | 行为 |
|---|---|---|
| 未判断 | 中性颜色 | 尚未通过左右滑动做出判断 |
| 已掌握 | 绿色 | 进入第 3 页已掌握卡片 |
| 未掌握 | 红色 | 进入第 3 页未掌握卡片，并在以后再次安排 |

颜色之外还必须保留图标和文字语义，避免色觉差异导致用户无法判断状态。

## 8. 尚待确认的交互

1. 横向切换下一个主页面时，用户希望手指向左滑还是向右滑？
2. 注册是否强制绑定邮箱？当前建议强制验证邮箱，以支持密码找回和降低无效账号数量。
3. 多次重新生成的英语版本，是全部永久保存还是只保存用户最终选择的版本？

## 9. 已确定的检验与复习规则

- 检验模式采用歌词式句子列表和左右滑动判断。
- 向左滑表示已掌握，向右滑表示未掌握。
- 第 3 页只提供“已掌握”和“未掌握”两张卡片。
- 单词始终在原录音生成的句子语境中学习，不生成独立单词复习卡。
- 未掌握句子由系统按日期在明天或以后再次安排。
- 复习功能保持点击播放、自主跟读和左右滑动判断，不模仿背词软件的题型。
