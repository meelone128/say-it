# Say It MVP 产品需求文档

> 版本：0.10 草案  
> 状态：讨论中  
> 更新日期：2026-08-17

## 1. 产品概述

Say It 帮助中文用户把“自己想说但不会用英语自然表达”的内容，转换成适合学习和跟读的自然英语。

用户录制一段中文后，系统完成中文语音识别、自然英语转换、自动拆句、逐句语音生成和单词解释。一次中文录音及其生成的完整英语口语段落共同构成一个“学习单元”。用户在单元内部逐句学习，并可将没有掌握的句子抽取到复习计划中，在未来按复习节奏再次学习。

### 1.1 核心产品对象：学习单元

一个学习单元包含：

- 用户的一段中文录音。
- 中文语音识别文本。
- 一段完整、连贯、自然的美式英语口语表达。
- 从完整段落中拆出的有序英文句子。
- 每句话的独立音频。
- 句中单词的词典信息。
- 用户对每句话的掌握判断。

英语句子不能脱离所属学习单元随意重排；学习页首先呈现完整段落，再提供逐句学习能力。

### 1.2 核心价值

- 用户练习的是自己真正想表达的内容，而不是固定教材。
- 输出自然口语表达，而不是逐字直译。
- 将长表达拆成可以逐句听、读、理解和掌握的学习材料。
- 用户在练习表达的同时，可以通过点词解释顺带积累词汇，但单词记忆不是首版的主流程。

### 1.3 MVP 核心闭环

```text
录制中文
→ 确认中文识别结果
→ 生成自然英语
→ 自动拆成短句
→ 逐句播放和学习
→ 点击单词查看解释
→ 在检验模式中左右滑动判断句子
→ 将句子归入已掌握或未掌握
→ 以后再次安排未掌握句子
→ 登录后长期保存和跨设备同步
```

## 2. 已确认的产品方向

1. 目标用户不按年龄或职业细分：学生、职场人士及其他希望提高日常英语口语能力的中文用户都可以使用。
2. 用户录制中文，首版不把中英混说、方言或英文录音作为重点场景。
3. 输出自然、地道的美式日常口语，不以考试、雅思、托福或书面表达为目标。
4. 首版使用一档固定难度，暂定为易懂的日常中级表达；避免生僻词、书面词和过长句子。
5. 首版同时支持 iOS 和 Android，使用跨平台移动端技术。
6. 用户可以直接开始体验；使用自定义账号注册或登录后，可以长期保存学习单元、错句和复习进度，并跨设备同步。
7. 未登录时数据可以暂存在设备本地，清理数据或卸载 App 后可能丢失；登录后数据保存到账号。
8. 生成后的英文不允许用户手动修改；中文识别文本仍允许用户在生成前纠正。
9. 英语转换由大语言模型完成，具体模型和供应商在技术验证阶段确定。
10. 首版暂不提供实时对话、发音评分和付费订阅。

## 3. MVP 用户故事

### 3.1 录制中文

作为学习者，我希望录制一段中文，以便学习这段内容用英语应该怎样自然表达。

验收标准：

- 用户可以开始、暂停、继续和结束录音。
- 点击录音后，底层录音先启动，再显示短暂的“准备—开始说话”提示；提示期间也保留音频，避免截掉句首。
- 页面显示当前录音时长。
- 用户可以试听或删除本次录音。
- 单次录音最长 60 秒，到达上限后自动结束。
- 录音过短、为空或上传失败时有明确提示。

### 3.2 确认中文识别结果

作为学习者，我希望看到并修改语音识别得到的中文，以免识别错误影响英语结果。

验收标准：

- 上传后显示中文识别文本。
- 用户可以编辑识别结果。
- 用户确认后才进入英文生成阶段。
- 用户可以返回重新录音。

### 3.3 生成自然英语

作为学习者，我希望系统将中文转换成自然英语，而不是生硬的逐字翻译。

验收标准：

- 英文保留中文原意，不擅自增加关键事实。
- 表达适合日常口语场景。
- 使用易懂的日常中级词汇和句式。
- 避免考试化、书面化或刻意复杂的表达。
- 生成后的英文不提供手动编辑入口。
- 生成失败时允许重试。
- 用户对结果不满意时可以多次重新生成。
- 每次重新生成都以同一份已确认中文内容为输入。
- 重新生成前保留当前结果，用户可以比较并选择一个版本作为学习内容。
- 页面明确提示 AI 结果可能存在偏差。

### 3.4 自动拆句

作为学习者，我希望英文被拆成较短句子，以便逐句理解和跟读。

验收标准：

- 句子按照原始语义顺序排列。
- 每句话可以独立显示和播放。
- 拆句不能破坏英文语义。
- 过长句优先改写或拆分为更易学习的表达。

### 3.5 逐句播放

作为学习者，我希望单独播放每句话，以便反复听和模仿。

验收标准：

- 每句话都有独立播放按钮。
- 播放时显示当前播放状态。
- 用户可以暂停和重新播放。
- 同一时间只播放一段音频。
- 音频生成失败时不阻塞文本学习，并允许单独重试。

### 3.6 点击单词查看解释

作为学习者，我希望点击英文单词查看它在当前句子中的含义。

验收标准：

- 英文句子中的单词可以点击。
- 单词详情以英语学习词典的形式呈现，而不是只显示一行翻译。
- 解释包含当前语境下的中文含义、常用含义和词性。
- 展示音标，并支持播放美式单词发音。
- 展示单词原形、常见词形变化和必要的语法信息。
- 展示贴近日常口语的英文例句及中文解释。
- 对当前句子中的用法进行简明说明。
- 标点不能被识别为单词。
- 重复点击相同单词不重复产生不必要的 AI 请求。

### 3.7 检验模式判断整句

作为学习者，我希望像浏览歌词一样逐句检验，并通过左右滑动判断每句话是否掌握。

验收标准：

- 每句话初始为未标记状态，使用中性视觉样式。
- 用户上下滑动浏览句子，点击句子播放标准音频并自行跟读。
- 用户向左滑后，句子归入“已掌握”。
- 用户向右滑后，句子归入“未掌握”。
- 判断完成后，该句从本轮检验队列移出并进入下一句。
- 待复习句子从原学习单元中抽取出来，加入用户的复习计划，但仍保留原学习单元关系和上下文。
- 系统为未掌握内容记录下次出现日期，用日期安排控制它在明天或以后再次出现。
- 同一句话不能同时处于已掌握和待复习状态。
- 用户收藏单词时，不创建独立单词卡；系统把单词所在的完整句子加入“未掌握”列表，并在句中突出该单词、标明来源学习单元。

### 3.8 按计划复习错句

作为学习者，我希望没有掌握的内容在明天或以后重新出现，但复习操作仍然保持简单。

验收标准：

- 第三个主页面通过“已掌握”和“未掌握”两张卡片分别查看句子。
- 每条笔记始终直接显示完整英文句子，不设置隐藏答案、揭晓答案或考试题型。
- 用户点击句子即可播放标准英语音频，然后自行跟读。
- 用户在再次检验时滑向“已掌握”，句子转入已掌握列表。
- 用户滑向“未掌握”，句子继续保留，并按日期安排在明天或以后再次被优先提醒。
- 移出的内容不物理删除，仍保留在原学习单元和历史记录中。
- 登录用户的复习进度保存到账号；未登录用户只保存在本机。

### 3.8.1 日期安排原则

- 只借鉴主流学习产品“根据日期再次出现”的思路，不复制它们的学习题型和页面操作。
- 首版为每条未掌握句子保存 `next_review_at`，用于决定明天或以后何时再次进入检验，不限制用户随时查看。
- 新加入或被判断为未掌握的内容优先安排在较近日期再次出现；用户没有处理的到期内容继续保留。
- 判断为已掌握后立即转入已掌握列表，不要求连续多次判断。
- 首版不做复杂记忆评分、隐藏答案、拼写测试或独立单词复习。
- 具体日期间隔作为可调整配置，先通过真实试用确定，不在界面暴露算法概念。

### 3.9 保存与同步学习数据

作为学习者，我希望通过账号保存学习单元和复习进度，以免更换设备或卸载 App 后丢失。

验收标准：

- 用户可以注册、登录和退出账号。
- 首版账号采用自定义用户名和密码；建议绑定邮箱用于验证和找回密码。
- 未登录时允许体验核心录音和生成流程。
- 登录后保存学习单元、用户最终选择的生成版本、错句、复习计划和掌握进度。
- 用户登录后可以将本机尚未同步的数据合并到账号。
- 用户可以删除学习单元或注销账号，并删除对应云端数据。

### 3.10 命名并保存学习单元

作为学习者，我希望为转换成功的英语段落命名并保存，以便稍后找到并学习。

验收标准：

- 转换完成后展示中文与英文段落对照。
- 用户保存前需要输入一个学习单元名称。
- 系统可以根据中文内容提供一个默认名称，用户可以修改。
- 保存后学习单元出现在“学习”主页面顶部。
- 已保存的学习单元允许重命名和删除。
- 未完成命名或保存时，系统不能悄悄丢失已经生成的结果。

## 4. 页面范围

四个主页面采用横向分页布局，用户通过左右滑动切换。页面内部的列表使用上下滑动。首版不使用底部 Tab 栏。

### 4.1 录音主页面

- 这是用户打开 App 后默认看到的第一个页面。
- 空闲状态以录音按钮作为唯一主要操作。
- 点击录音按钮后立即启动底层录音，并通过清楚的“现在可以说话”反馈提示用户，再录制中文段落。
- 录音完成后显示转换进度。
- 转换完成后显示中文与英文段落对照。
- 用户为段落自定义名称并保存为学习单元。
- 保存完成后自动切换到第二个主页面，并在列表顶部显示新学习单元。

### 4.2 录音页

- 录音控制。
- 时长和音量反馈。
- 试听、删除和提交。
- 麦克风权限说明。

### 4.3 中文确认页

- 展示识别文本。
- 编辑中文。
- 确认生成英语。
- 返回重新录制。

### 4.4 转换状态

- 显示当前阶段，例如“正在识别”“正在生成自然英语”“正在生成语音”。
- 允许用户离开页面，后台继续处理。
- 失败时显示可理解的错误和重试入口。

### 4.5 学习主页面

- 这是横向分页中的第二个主页面。
- 按最近保存时间展示学习单元列表。
- 刚刚保存的学习单元出现在列表顶部。
- 每个学习单元以一张已保存卡片展示。
- 卡片主要展示用户自定义名称和保存时间。
- 卡片采用接近正方形的尺寸，并沿页面纵向左右交错排列，而不是整齐的单列或双列网格。
- 收藏的学习单元可以显示实心五角星，并优先排列。
- 点击列表项进入该学习单元的学习详情。

### 4.6 学习单元详情页

- 页面顶部同一行依次放置返回箭头、五角星收藏图标和圆形“检”字图标。
- 五角星用于收藏或取消收藏当前学习单元；空心表示未收藏，实心表示已收藏。
- 圆形“检”字图标采用圆润、幼态的视觉风格，与五角星尺寸和视觉重量接近；点击后进入检验模式。
- 展示中文原文和自然英语。
- 以一个完整段落呈现本次学习单元的英语内容。
- 提供“全部播放”，按顺序朗读完整英语段落。
- 文章学习模式中，中英文段落对照展示；每句可以点击播放并跟读。
- 点击英文单词打开对应的词典详情。
- 单词可点击。
- 展示单词解释面板。
- 提供独立的“检验模式”。
- 检验模式中，英文像歌词列表一样按句纵向排列并支持上下滑动。
- 用户向左滑句子，将其归入已掌握；向右滑句子，将其归入未掌握。
- 对生成结果不满意时可以重新生成，并从多个生成版本中选择学习版本。

### 4.7 学习记录主页面

- 这是横向分页中的第三个主页面。
- 页面只显示“未掌握”和“已掌握”两张主要卡片及各自句子数量。
- “未掌握”卡片放在上方，优先展示需要继续学习的内容和今日到期数量。
- “已掌握”卡片放在下方，作为用户的学习成果记录。
- 点击“已掌握”查看已经掌握的句子。
- 点击“未掌握”查看需要继续学习的句子。
- 每条句子显示来源学习单元，点击即可播放并跟读。
- 用户收藏单词时，该单词所在的完整句子进入未掌握列表，收藏词在句中高亮。
- 同一个来源句子只保留一条状态记录，不能同时出现在两个列表中。
- 未掌握句子根据日期在明天或以后重新进入检验。
- 到期的未掌握句子排在列表前面；未到期内容仍可随时查看。
- 未掌握列表中向左滑表示已掌握，句子转入已掌握列表；向右滑表示仍未掌握并继续保留。
- 已掌握列表中的句子如果后来发现仍未掌握，可以向右滑重新放回未掌握列表。
- 进入任一句子列表后暂时关闭四个主页面的横向切换手势，返回第三个主页面后恢复，避免手势冲突。

### 4.8 账号与设置主页面

- 这是横向分页中的第四个主页面。
- 使用自定义用户名和密码注册、登录和退出。
- 绑定或修改找回密码邮箱。
- 查看当前同步状态。
- 将本机学习数据同步到账号。
- 管理账号和基础 App 设置。
- 删除账号及云端学习数据。

## 5. 非功能要求

### 5.1 性能

- 录音上传成功后立即进入可追踪的处理状态。
- 30 秒录音的目标处理时间不超过 30 秒；最终指标需要通过真实模型测试确定。
- 已生成的句子音频再次播放时应直接使用缓存。

### 5.2 隐私

- 上传录音前向用户说明用途。
- 未登录用户的数据只保存在当前设备，登录用户的数据通过账号同步。
- 服务端录音和生成内容使用不可猜测的临时访问地址。
- 用户保存的学习单元需要按照账号数据策略保留；临时或未保存内容按保留策略自动删除。
- 日志不得记录完整录音、访问令牌或不必要的个人内容。

### 5.3 可靠性

- AI 流水线各阶段能够独立重试。
- 重试不能生成重复练习或重复扣费记录。
- 即使语音尚未生成，已经生成的文本仍应可以查看。
- 左右滑动判断和出现日期需要保留操作记录，重复提交时不能重复修改状态。

### 5.4 可观测性

- 记录各处理阶段的耗时、成功率和错误类型。
- 记录每次练习使用的模型、Prompt 版本和输出难度。
- 能统计单次练习的估算 AI 成本。

## 6. 首版明确不做

- 用户英语发音评分。
- 实时 AI 语音对话。
- 直播或社交学习。
- 排行榜和打卡体系。
- 复杂的个性化记忆算法；首版使用固定间隔规则。
- 教师后台。
- 复杂会员和支付系统。
- 多人共享练习。

## 7. 产品验证指标

MVP 发布后优先观察：

- 完成一次“录音到学习页”的用户比例。
- 英文生成后的重新生成比例。
- 每次练习的平均句子播放次数。
- 单词解释点击率。
- 用户在检验模式中完成左右滑动判断的比例。
- 到期错句复习完成率。
- 未掌握句子后续转为已掌握的比例。
- 学习单元保存率和账号同步成功率。
- AI 流水线成功率和平均处理时间。

## 8. 上线前核心测试集

需要准备至少 30～50 条中文真实表达，覆盖：

- 日常生活。
- 工作和学习。
- 情绪和态度。
- 请求、拒绝和建议。
- 包含时间、数字、人名的表达。
- 口头语、停顿和不完整句。
- 较长且需要拆分的表达。

每条测试需要人工评价：

- 是否忠实原意。
- 是否自然。
- 是否符合目标难度。
- 拆句是否合理。
